# Prior work

> If your project existed before the hackathon, a clear explanation of
> what you built or changed during the submission window.

**Sideline did not exist before this hackathon.** Everything in this
repository was written during the submission window: the MCP server, the
nine tools, the state model, the poller, the providers, the language
layer, the tests and the documentation.

No pre-existing codebase was adapted, and no component was carried over
from earlier work.

| MCP specification 2025-11-25 | Open standard, implemented from the spec with no SDK |
| Python standard library | — |
| boto3 | AWS SDK, used for Bedrock and DynamoDB |

Nothing else is vendored or copied.
